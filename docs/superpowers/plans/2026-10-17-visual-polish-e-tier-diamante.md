# Polimento Visual e Tier de Diamante Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a Diamond tier to horseshoes and saddlebags (Netherite now upgrades from Diamond), replace the flat saddlebag overlay with a 3D side-bag model, add empty-slot silhouette icons, and give saddlebags detailed leather-bag item icons — all art generated by a versioned Python script.

**Architecture:** A deterministic Pillow script in `tools/pixelart/` writes every new PNG into `src/main/resources/assets/strideandsire/...`; PNGs are committed (the Gradle build never runs Python). The Diamond tier is a new constant in `HorseshoeMaterial`/`SaddlebagMaterial` plus the usual item/recipe/tag/lang/model wiring; the two Netherite smithing JSONs change their `base` from the Iron item to the Diamond item. The 3D bags are a client-only model layer whose parts copy the horse body's pose each frame; the existing common seam `SaddlebagRendering.materialToRender` stays the single visibility rule.

**Tech Stack:** Minecraft Forge 66 (MC 26.3), Java 25, Forge GameTest (data-driven harness in `gametest/ModGameTests` + `data/strideandsire/test_instance/*.json`), JUnit 5, Python 3.12 + Pillow 11 (dev-time only).

**Spec:** `docs/superpowers/specs/2026-10-17-visual-polish-e-tier-diamante-design.md`

## Global Constraints

- Loader is MinecraftForge 66 / MC 26.3 (not NeoForge). Follow existing repo patterns: `DeferredRegister` + `RegistryObject` in `registry.ModItems`; GameTests registered in `gametest/ModGameTests` with a `test_instance` JSON each (Forge's `@GameTest` annotation registers nothing). Client classes only in `client/`, never referenced from common code or GameTests.
- Diamond Horseshoe: durability 300; exclusive enchantments Feather Step + Frost Step (not Lava Walker); no passive; enchantability 10; recipe "U" of 5 `minecraft:diamond` (`D D` / `D D` / ` D `); id `strideandsire:diamond_horseshoe`; names "Diamond Horseshoe" / "Ferradura de Diamante"; creative tab between Iron and Gold horseshoes.
- Diamond Saddlebag: 9 slots (18 with Draft, unchanged Fase C rule); protects contents from explosion: yes; from fire/lava: no; Piglin neutrality: no; recipe `D D` / `L L` / `LLL` (2 diamonds + 5 leather); id `strideandsire:diamond_saddlebag`; names "Diamond Saddlebag" / "Alforje de Diamante"; bonus tooltip "Contents survive explosions" (pt_br equivalent, same wording as Iron's line); creative tab between Iron and Gold saddlebags.
- Netherite Horseshoe upgrade base becomes `strideandsire:diamond_horseshoe` (Iron no longer accepted); still preserves enchantments and damage ratio (150/300 → 200/400) and still rejects bases carrying enchantments Netherite can't hold.
- Netherite Saddlebag upgrade base becomes `strideandsire:diamond_saddlebag` (Iron no longer accepted); container contents preserved exactly.
- Item icon palette per tier (metal of buckle/corners): Leather = plain stitching + dark-leather buckle; Iron grey; Gold yellow; Diamond cyan; Netherite dark grey with purple sheen. Bag body is always brown leather.
- Empty-slot sprite ids: `strideandsire:container/slot/horseshoe` and `strideandsire:container/slot/saddlebag` (files `assets/strideandsire/textures/gui/sprites/container/slot/{horseshoe,saddlebag}.png`, 16×16).
- Art script is deterministic (same script → byte-identical PNGs) and supports `--check` (exits non-zero if any expected file is missing or has the wrong size).
- Never `git add -A`/`git add .`: the user's untracked `README.md`, `README.pt-BR.md`, `docs/images/` must not be committed. Add files explicitly.

## Review Focus

- A tier missing one of its textures shows the purple/black missing texture in game — every tier must have item icon + entity texture (pinned by `AssetCompletenessTest`, Tasks 1/2/4/6).
- A player with an Iron Horseshoe/Saddlebag in the Smithing Table expects no Netherite result now (no silent upgrade) and a Diamond one to upgrade — both directions tested (Tasks 3, 4).
- A Diamond Horseshoe enchanted with Frost Step must not upgrade (same rejection as Iron had) (Task 3).
- The saddlebag slot shows its silhouette on a saddle-less horse but must still refuse a saddlebag there (Task 5).
- Foals, unsaddled horses and horses without a bag must not draw 3D bags; Donkey/Mule with chest still draw them (Task 6 — seam test + manual client check).
